Overview
This repository contains data analysis and machine learning projects developed as part of the AI Certificate Program at ReDI School of Digital Integration, Denmark.
The projects apply Python, Pandas, statistical analysis, and machine learning to explore real-world datasets — covering data cleaning, exploratory analysis, statistical measures, model training, and evaluation.

Projects
1. COVID-19 Global Data Analysis
Week 02 | Python & Pandas
Exploratory analysis of real-world global epidemiological data. Covers country filtering, mortality rate calculation, yearly aggregation, and data visualisation.
FileDescriptionSpring2025AI_Week02_IntroToPython_handsOn.ipynbClass exercise: global COVID-19 data exploration, multi-country filtering, mortality rate analysis, and visualisationbrazil_pratice.ipynbIndividual assignment: filtering, analysing, and visualising COVID-19 mortality data specifically for Brazil

2. World Tourism Statistics Analysis
Week 03 | Introduction to Statistics
Statistical analysis of 25 years of global tourism data (1999-2023) covering 266 countries. Applies measures of central tendency and spread, and develops four visualisations to uncover real-world patterns including the impact of COVID-19 on global tourism.
FileDescriptiontourism_analysis.ipynbIndividual assignment: statistical analysis and visualisation of global tourism arrivals and receipts, including top 10 countries ranking

3. Credit Risk Classification
Week 04 | Machine Learning — Supervised Learning
Binary classification model to predict whether a bank client represents high or low credit risk, based on financial and demographic data. Applies logistic regression with 97% accuracy on test data.
FileDescriptioncredit_risk_classification.ipynbFull ML pipeline: data cleaning, encoding, train/test split, logistic regression model, confusion matrix, and evaluation

Key Concepts Applied

pandas — DataFrame loading, inspection, filtering, groupby aggregation, column creation
matplotlib — Histogram, box plot, line chart, bar chart, and confusion matrix visualisations
scikit-learn — Logistic Regression, train/test split, LabelEncoder, classification report
Statistical analysis — mean, median, mode, variance, standard deviation, IQR
Machine learning — supervised learning, binary classification, model evaluation
Data cleaning — handling missing values, encoding categorical variables, type management
